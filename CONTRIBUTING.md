# Contributing

As we all know, we as humans make mistakes. Therefore, I highly appreciate your feedback and contributions if you see an issue or an improvement for this skillset.

## Issues

Before submitting a new issue, please review the [existing issues](https://github.com/feevlic/aaos-vhal-skills/issues) to avoid creating duplicates.

If you've found a bug or have a great idea for a new feature, please submit a [new issue](https://github.com/feevlic/aaos-vhal-skills/issues/new/choose). I have provided specific templates to make this process easier for everyone:

- **Bug Report:** Use this template if you experience unexpected behavior or errors with the skills.
- **Feature Request:** Use this template to suggest new ideas or improvements to the project.

Also, if you feel really generous, consider resolving current issues or contributing to the discussion on an issue.

Thank you!
